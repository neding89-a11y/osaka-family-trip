# 오사카 가족여행 - 표시 오류 수정본

## 파일
- `index.html`: 이미지·본문·스타일·스크립트가 포함된 단일 HTML. 외부 지도 라이브러리 없음.
- `maps/`: 동일한 지도 PNG 원본.
- `data.json`: 기존 일정 및 후보 데이터.

## 핵심
자바스크립트 OFF에서도 8일 일정·지도·식당/카페/기저귀/교통정보가 HTML 본문에 존재합니다.
자바스크립트 ON이면 일정 선택 시 지도 확대/상세 정보 연동과 체크 저장을 사용합니다.

## 지도 주의
다운로드판은 오프라인 참고지도입니다. 도로/공원은 개략화하였고 핀은 입구 좌표가 아닐 수 있습니다.
실제 길찾기는 링크를 이용하세요. 숙소는 스크린샷 기반 추정 위치입니다.
운임·메뉴는 이전 계획값으로 최신 검증을 새로 하지 않았습니다.

## GitHub Pages
저장소 루트에 `index.html`과 `.nojekyll` 업로드 후 Settings → Pages에서 main / root를 배포 대상으로 설정합니다.
이 ZIP 자체는 배포가 아닙니다. 실제 공개 URL은 GitHub Pages 설정 후 표시된 주소를 사용하세요.
가족의 정확한 숙소 주소·예약번호·연락처는 공개 페이지에 넣지 마세요.
